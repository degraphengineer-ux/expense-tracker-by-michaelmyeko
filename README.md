# 💸 Expense Tracker

**By Michael Myeko**

A sleek, intuitive, and modern web application designed to help users take control of their finances. This expense tracker allows users to seamlessly log their daily transactions, categorize their spending, and monitor their financial health through a clean and responsive user interface.

## ✨ Features

- **Real-Time Tracking:** Instantly add, edit, or delete income and expense records.
- **Smart Categorization:** Organize transactions by category (e.g., Food, Transport, Entertainment) for better budgeting insights.
- **Dynamic Balance Updates:** Automatically calculates total income, total expenses, and the current available balance.
- **Modern UI/UX:** A clean, visually engaging layout prioritizing user experience and accessibility across all devices.
